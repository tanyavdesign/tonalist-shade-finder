Hold a patch of clear, bare skin — cheek, jaw, neck, inner arm, wherever — inside the box, close enough that skin fills it completely with no hair or background inside it. The screen is your only light source and it's weak at arm's length, so get close. Find even, indirect light and turn your screen brightness to maximum.

Each reading uses seven full-screen colour flashes, about six and a half seconds in total, to measure how your camera and screen respond before it measures your skin. The screen changes colour slowly rather than strobing. Take as many samples as you want — move to a different patch of skin and press the button again each time. If flashing light is a problem for you, don't run it.

Set your device's own screen brightness to maximum before starting — there is no way for a web page to do this for you, so it has to be done in your phone's system settings first. Starting the camera does keep the screen from dimming or locking mid-sequence.
